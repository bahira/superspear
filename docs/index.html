The method

Evolution, not approximation.

A population of algebraic trees competes on accuracy ↔ parsimony. Transcedental operations are allowed but priced honestly — an exp costs ~20 ALU/SFU units against 1 for a multiply — so the search is biased toward cheap, deployable algebra. Every discovery is reproducible from a single seed: same seed, same data, same formulas, same metrics.

The honest multipliers

Cheap O(1) formulas beat loops.

Where practitioners normally run an iterative solver, SPEAR finds a closed form. Counting the solver's full bill — every iteration, in the same ALU/SFU units — the accelerations are legitimate, measured, and reported even when the discovered formula is slower.
