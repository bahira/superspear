The method

Evolution, not approximation.

A population of algebraic trees competes on accuracy ↔ parsimony under NSGA-II. Transcendental ops are allowed but priced honestly (~20 ALU/SFU units vs 1 for a multiply), so the search is biased toward cheap deployable algebra. An out-of-distribution gate rejects formulas that only interpolate; past champions seed every new run. Same seed ⇒ same formulas.
